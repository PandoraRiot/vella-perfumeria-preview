# Vella Perfumería — vista previa

Vista previa estática del catálogo de Vella Perfumería (GitHub Pages): catálogo, filtros por
género, marca y precio, búsqueda y pedidos por WhatsApp. No incluye carrito ni pagos; la tienda
completa vive en un repositorio privado.

Los datos (`data/catalogo.json` e `img/`) se exportan desde la tienda con
`scripts/preview/exportar.mjs`. La página no se indexa en buscadores (`noindex`) hasta el lanzamiento.
